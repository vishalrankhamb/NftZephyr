# NftZephyr

NftZephyr implements a blockchain-based, event-driven architecture for real-time data and auto-scaling on a decentralized validator network of nodes.

The key benefits of using NftZephyr include:

- NftZephyr implements a blockchain-based, event-driven
- architecture for real-time data and
- auto-scaling on a decentralized validator

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftZephyr.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
